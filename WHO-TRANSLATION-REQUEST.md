## Where WHO's material will be used (paste)

This request extends licence 202610340, granted on 3 September 2026, which allows the Pocket book of hospital care for children, 2nd ed., to be reproduced in Orbweaver, a free offline clinical reference application for health workers in low-resource district hospitals. That licence was granted without translation. This request is for a Spanish translation of the same material, shown in the same application to users who choose Spanish, for health workers in Latin America.

I could not find a WHO or PAHO Spanish edition of the 2nd edition. If one exists, I would rather reproduce it than use my own translation.

The translation is in neutral Latin American Spanish. I made it with the help of an AI model, page by page. Every page has been checked by software against the English for numbers, doses, units, signs such as < and ≥, and layout, and every page passed. Dosing pages will be reviewed by a Spanish-speaking clinician before release.

The English remains the original. The application would show the translation disclaimer WHO requires on the credits screen, alongside the citation already required by licence 202610340, using whatever wording WHO specifies.

Nothing else changes: the application is free, works offline, collects no data, and has no advertising, analytics or in-app purchases.

Before I re-read the licence, the Spanish text was posted for about a day to a public code repository for the application, on a development branch. It was never released in the application. When I saw that the licence does not cover translation, I removed it from the repository and its history on 22 November 2026.
