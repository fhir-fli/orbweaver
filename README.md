# orbweaver

## 📋 OPENEVIDENCE.md — the file to paste

Everything waiting on a clinical answer is in **`OPENEVIDENCE.md`** at the root of this repo. Its first line says how many items are open. Paste a whole `## Q` section into OpenEvidence; each one is self-contained and names no file, section number or commit, because OpenEvidence cannot see them.

Answered questions are deleted from it, not annotated. The rulings and the reasoning live in `tool/crossbook/*_adjudication.md` and `tool/protocolbook_source_errata.md`.
